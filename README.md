A web-based Hotel Management System developed using PHP and MySQL as the HNDIT Final Year Project.
### Technologies Used
-Frontend: HTML, CSS, JavaScript
-Backend: PHP
-Database: MySQL (red_lion_hotel.sql)
-Server: XAMPP

### Key Features
-Room Booking and Reservation
-Customer Management
-Admin Panel for Room Management
-Booking History

### How to Run
1. Copy the project folder to  htdocs
2. Import red_lion_hotel.sql to phpMyAdmin
3. Run on Localhost
